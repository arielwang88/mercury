# Mercury

Mercury is a lightweight workspace for practical TPM tools.

## Mercury Brief

Mercury Brief is a small static app that turns messy TPM source notes into a
structured status update. Paste notes from Slack, standup, Jira, or meeting docs,
then generate an editable brief with updates, actions, risks, blockers, and
decisions.

## Run locally

Open `index.html` in a browser.

## Validate

```bash
npm test
```
